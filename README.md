## Projetos em destaque

### [Atlas de Processos](https://github.com/jpvmachado/atlas-de-processos)

Aplicação web com uma base de conhecimento fictícia e um assistente que localiza orientações em linguagem natural.

- **Busca tolerante a erros:** normaliza a consulta, reconhece sinônimos e ordena os resultados por relevância.
- **Respostas com fontes:** seleciona trechos do catálogo, usa o contexto da pergunta anterior e aponta para a seção que sustenta a resposta.
- **Testes:** verifica busca, contexto, ausência de evidência e fidelidade à fonte.

**Tecnologias:** HTML, CSS, JavaScript e Node.js para testes. O motor de busca roda no navegador.

### [Jornada de Clientes](https://github.com/jpvmachado/jornada-clientes1)

Aplicação web com dados fictícios para acompanhar pendências, histórico, SLA e produtividade.

- **Importação resiliente:** valida os registros e grava em lotes. Uma carga interrompida retoma do último lote confirmado, sem regravá-lo.
- **Dados e indicadores:** organiza os registros em bases segmentadas e consolida informações para acompanhar a operação.
- **Governança:** mantém histórico de importação e verifica conflitos antes de reverter uma carga.

**Tecnologias:** Google Apps Script, Google Sheets, HTML, CSS e JavaScript.
